# Как помочь проекту

[← README](../README.md)

Спасибо, что заглянули! Вот чем можно помочь — от самого простого к сложному.

## Сообщить о проблеме

Откройте [issue](https://github.com/StormMagic1337/ardor-rgb/issues) и укажите:

- модель клавиатуры и способ подключения;
- версию Windows и Python (`python --version`);
- что написано в строке состояния внизу окна («Клавиатура: …»);
- что ожидали и что произошло; для проблем с подсветкой — фото или видео очень помогают.

Частые причины:

| Симптом | Что проверить |
|---|---|
| «нет клавиатуры» | подключена ли кабелем; закрыт ли Guardian (в том числе в трее) |
| подсветка мигает / прыгает между режимами | запущен Guardian или вторая копия программы из другой папки |
| `ModuleNotFoundError: hid` или `AttributeError: module 'hid' has no attribute 'device'` | установлен пакет `hid` вместо `hidapi`: `pip uninstall hid` и `pip install hidapi` |
| эквалайзер не реагирует | играет ли звук на устройстве **по умолчанию**; установлен ли `PyAudioWPatch` |
| не работают хоткеи | сочетание занято другой программой — при старте будет уведомление в трее |

## Новая модель клавиатуры

Если у вас другая клавиатура на контроллере `320F:5055` (не обязательно ARDOR), программа, скорее всего, её найдёт, но клавиши будут гореть «не там». Чтобы добавить поддержку, нужна **карта светодиодов**.

### 1. Проверить, что устройство то же

```powershell
python -c "import hid; [print(hex(d['usage_page']), d['product_string']) for d in hid.enumerate(0x320F, 0x5055)]"
```

В списке должен быть интерфейс с usage page `0xff1c`.

### 2. Снять карту

Закройте Guardian и ARDOR RGB, затем:

```powershell
python tools/probe.py                    # индексы по умолчанию
python tools/probe.py 0 1 2 3 15 16 30   # или только нужные
```

Утилита зажигает светодиоды по одному белым на тусклом синем фоне и для каждого индекса спрашивает, какая клавиша загорелась. Введите название клавиши, `ничего` или просто Enter, чтобы пропустить. Результат сохранится в `probe_result.json`.

Чтобы снять всю карту, передайте все индексы:

```powershell
python tools/probe.py (0..127)
```

### 3. Прислать результат

Откройте issue с названием модели, файлом `probe_result.json` и фотографией клавиатуры сверху — по ней снимаются координаты клавиш. Если хотите сделать всё сами — см. ниже, как устроен [`ardor/layout.py`](../ardor/layout.py).

### Как устроена карта

- `NAMES` — названия клавиш в порядке индексов светодиодов (`_` — пустой слот).
- `_ROWS` и `_EXTRA` — координаты центров клавиш в единицах ширины клавиши.
- `MIRROR` — клавиши с двумя слотами светодиодов, которые должны получать одинаковый цвет (иначе клавиша мерцает).
- `_VK` — виртуальные коды Windows для реакции на нажатия.

Сейчас карта одна и задана константами. Поддержка нескольких моделей потребует выбора карты по модели — это хорошая первая большая задача для контрибьютора.

## Код

### Окружение

```powershell
git clone https://github.com/StormMagic1337/ardor-rgb.git
cd ardor-rgb
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install pillow          # только для tools/render_previews.py
```

### Стиль

- Код и комментарии — на английском, тексты интерфейса — на русском.
- Короткие модули, докстринг в начале каждого файла: что он делает и зачем.
- Комментарии объясняют «почему», а не «что».
- Эффекты — векторно на NumPy, см. [советы в EFFECTS.md](EFFECTS.md#советы).

### Проверка изменений

Автотестов пока нет. Перед pull request:

1. `python run.py --list` — всё импортируется, эффекты на месте.
2. `python run.py <эффект>` — эффект работает на клавиатуре; `Ctrl+C` возвращает исходную подсветку.
3. `pythonw app.py` — окно открывается, ползунки меняют эффект, настройки сохраняются после перезапуска.
4. Если меняли эффект — обновите превью и каталог: `python tools/render_previews.py --all` и `python tools/gen_effects_doc.py`.

### Pull request

- Одна задача — один PR.
- В описании: что изменилось и как проверяли.
- Новый эффект — с описанием на двух языках в `TEXT` в [`tools/gen_effects_doc.py`](../tools/gen_effects_doc.py), превью (`render_previews.py --all`) и перегенерированными [EFFECTS.md](EFFECTS.md) / [EFFECTS.en.md](EFFECTS.en.md).

## Разбор новых команд клавиатуры

Утилита [`tools/sniff_steps.py`](../tools/sniff_steps.py) запускает Guardian под [Frida](https://frida.re/) и по шагам подсказывает, какую настройку переключить; после каждого шага в лог пишется метка. Так по логу однозначно видно, какой пакет за что отвечает.

```powershell
pip install frida                  # один раз
python tools\sniff_steps.py        # из PowerShell от администратора: Guardian требует прав админа
```

Перед запуском закройте ARDOR RGB. Лог сохраняется в `tools/sniff_steps.log`. Шаги задаются списком `STEPS` в начале файла — их легко поменять под нужную настройку.

## Идеи

- Готовый `.exe` (PyInstaller) и переделка автозапуска под него.
- Работа по радио (2.4 ГГц) — протокол уже проверен, см. [PROTOCOL.md](PROTOCOL.md#беспроводной-режим-24-ггц).
- Настройки клавиатуры в окне (блокировка Win, WASD ↔ стрелки, anti-ghosting, частота опроса, автоповтор) — нужен лог `sniff_steps.py`.
- Поддержка нескольких моделей клавиатур.
- Новые эффекты — особенно реагирующие на игры и систему (температура, сеть).
- Английская локализация интерфейса.
