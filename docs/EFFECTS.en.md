# Effects

[Русская версия](EFFECTS.md) · [← README](../README.en.md)

All effects live in [`ardor/effects/`](../ardor/effects/) and **all of them are original**: every frame is computed by the program, none of the effects comes from the keyboard firmware. The order of the sections below is the order in the window and for `Ctrl+Alt+←/→` (the "Off" effect is skipped by the hotkeys).

The code in each heading is the identifier used by `run.py` and `settings.json`. The app's UI is in Russian, so the tables show the label you will see in the window next to the parameter key. A "hue" is a position on the HSV colour wheel (0 = red, 0.33 = green, 0.66 = blue, 1 = red again); the window shows a rainbow slider for it.

**Key-press reactions** are switched off in calm mode. The previews are animations rendered by the app itself (the same widget as in the window); key presses and music in them are synthetic. The catalogue below is generated by [`tools/gen_effects_doc.py`](../tools/gen_effects_doc.py): the parameter tables come straight from the code.

### Weather outside (Погода за окном) — `weather`

![Погода за окном](media/effects/weather.webp)

Shows the actual weather in a chosen city (data from [Open-Meteo](https://open-meteo.com/), no API key, refreshed every 10 minutes): rain, snow or blizzard, thunderstorm, clear sky (warm with a sun by day, stars and meteors at night), clouds, fog. Rain and snow strength follow the precipitation, wind follows the real wind. Changes blend over 3 s; a summary is shown in the status bar. "Показать" lets you pick any weather by hand (the preview shows "clear").

**Key press:** in rain, snow and thunderstorm, the same as those effects; none for clear sky, clouds and fog.

| Parameter | Label in the app (RU) | Type | Range | Default |
|---|---|---|---|---|
| `city` | Город | text | — | Новосибирск |
| `force` | Показать | choice | Авто (как на улице) / Ясно / Переменная облачность / Пасмурно / Туман / Дождь / Снег / Гроза | Авто (как на улице) |

## Writing your own effect

### 1. API

```python
class Effect:
    name = ""        # identifier: run.py, settings.json
    title = ""       # name shown in the window
    params = []      # list of Param; the window builds its controls from it

    def reset(self): ...                               # create state (called from __init__)
    def render(self, t, dt, presses, calm): ...        # return a frame
```

`render` is called 60 times per second with:

| Argument | Meaning |
|---|---|
| `t` | seconds since the engine started |
| `dt` | duration of the previous frame, ≤ 0.1 s |
| `presses` | indices of keys pressed since the previous frame (empty in calm mode) |
| `calm` | `True` in calm mode |

and returns an **`(N, 3)`** array of RGB colours in **0…1**, one row per key.

Available from `ardor/effects/base.py`:

| Name | Meaning |
|---|---|
| `X`, `Y` | key coordinates in key units: `x` 0…18.4 left to right, `y` 0…5.2 top to bottom |
| `N` | number of keys (97) |
| `hsv(h, s, v)` | vectorised HSV → RGB; arguments broadcast to `(N,)` |
| `rgb("ff8800")` | colour from hex |
| `Noise(rng)` | smooth 2D noise: `noise(x, y)` and fractal `noise.fbm(x, y, octaves)` |
| `self.p` | dict of the current parameter values |
| `self.rng` | NumPy random generator |

For grid-based effects (like "Fire") there is `layout.sample(grid)`, a bilinear sample of a grid at the key positions. A key's index by name: `layout.slot_of("Space")`.

`Param(name, title, lo, hi, default, kind, options)`, where `kind` is:
- `"float"`: slider (200 steps);
- `"int"`: slider with integer steps;
- `"hue"`: rainbow slider;
- `"bool"`: checkbox (value 0 or 1);
- `"choice"`: drop-down list, labels in `options`, the value is the item index;
- `"text"`: text field, the value is a string (e.g. the city in "Weather outside").

Numeric values arrive as `float`, even for `bool` and `choice`.

Optional method `info(self) -> str | None`: a line for the window's status bar (this is how "Weather outside" shows its summary).

### 2. Example: "Comet"

Create `ardor/effects/comet.py`:

```python
"""Comet: a bright dot flies along a row; a key press launches a comet from that key."""
import numpy as np
from .base import Effect, Param, hsv, X, Y, N


class Comet(Effect):
    name, title = "comet", "Комета"
    params = [
        Param("speed", "Скорость", 2.0, 20.0, 8.0),
        Param("tail", "Длина хвоста", 0.5, 6.0, 2.0),
        Param("hue", "Цвет", 0.0, 1.0, 0.08, "hue"),
    ]

    def reset(self):
        self.comets = []                                   # (start x, row, start time)

    def render(self, t, dt, presses, calm):
        p = self.p
        for k in presses:                                  # a key press launches a comet from that key
            self.comets.append((X[k], Y[k], t))
        if not self.comets:                                # no presses: a random row
            self.comets.append((-1.0, float(self.rng.integers(0, 6)), t))
        v = np.zeros(N)
        alive = []
        for x0, row, t0 in self.comets:
            head = x0 + (t - t0) * p["speed"]
            if head - p["tail"] > 19:                      # flew off the edge
                continue
            alive.append((x0, row, t0))
            behind = head - X                              # distance behind the head
            on_row = np.abs(Y - row) < 0.5
            v = np.maximum(v, on_row * (behind >= -0.5) * np.clip(1 - behind / p["tail"], 0, 1))
        self.comets = alive
        return hsv(np.full(N, p["hue"]), 1 - 0.5 * v, v)
```

### 3. Registration

```powershell

python tools/gen_effects_doc.py         # catalogue in EFFECTS.md and EFFECTS.en.md
```

The effect appears in the window automatically with its controls, and its settings are saved to `settings.json`.

### Tips

- **Think in vectors.** One `render` call should take a couple of milliseconds: compute the whole keyboard with one NumPy expression, not a loop over keys. A loop over "objects" (bolts, comets, rings) is fine while there are few of them.
- **Use `dt`, not frame counts.** Speeds in keys per second, decay via `np.exp(-dt / τ)`. The effect then looks the same at any FPS.
- **Background.** A faint background (`0.02…0.05`) makes an effect feel alive. Users who want real black switch on "True black" in the window: the engine turns off everything darker than the threshold, so you don't have to handle it.
- **Scale `y`.** Existing effects multiply `dy` by 1.1…1.6 in distance formulas; the factor was tuned by eye so that circles look round on the real keyboard.
- **Clip the result** with `np.clip(out, 0, 1)`. The engine clips too, but intermediate sums are easier to control.
