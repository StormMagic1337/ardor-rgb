# Эффекты

[← README](../README.md) · [Архитектура](ARCHITECTURE.md)

Все эффекты лежат в [`ardor/effects/`](../ardor/effects/). Порядок в списке ниже = порядок в окне и при переключении `Ctrl+Alt+←/→` (эффект «Выключено» хоткеями пропускается).

Колонка «Имя» — идентификатор для `run.py` и `settings.json`. Тип «цвет» — оттенок по кругу HSV (0 = красный, 0,33 = зелёный, 0,66 = синий, 1 = снова красный); в окне для него показывается ползунок с радугой.

**Реакция на нажатия** во всех эффектах отключается в спокойном режиме.

## Новые эффекты

### Гроза — `storm`

![Гроза](media/storm.gif)

Тёмные облака из фрактального шума плывут по ветру. Время от времени в них вспыхивают зарницы (рассеянный свет внутри облака) или бьют молнии: ломаный путь сверху вниз с 1–2 боковыми ветвями, яркое ядро и голубое свечение вокруг. Вспышка состоит из 1–3 импульсов с послесвечением — как настоящая молния. Поверх идёт дождь.

**Нажатие:** молния бьёт точно в нажатую клавишу.

| Параметр | Название | Тип | Диапазон | По умолчанию |
|---|---|---|---|---|
| `frequency` | Частота молний | число | 0 … 3 | 1 |
| `wind` | Ветер | число | 0 … 3 | 1 |
| `clouds` | Яркость облаков | число | 0 … 2 | 1 |
| `rain` | Дождь | число | 0 … 1 | 0,3 |

При `frequency = 1` молния бьёт в среднем раз в 6 секунд; `0` — только по нажатиям.

### Дождь — `rain`

![Дождь](media/rain.gif)

Капли падают со шлейфом, сносятся ветром и разбиваются о нижний ряд кольцами брызг. На нижних рядах мерцают «лужи».

**Нажатие:** брызги расходятся от нажатой клавиши.

| Параметр | Название | Тип | Диапазон | По умолчанию |
|---|---|---|---|---|
| `density` | Сила дождя | число | 0,1 … 3 | 1 |
| `speed` | Скорость капель | число | 0,3 … 2,5 | 1 |
| `wind` | Ветер | число | −2 … 2 | 0,3 |
| `hue` | Цвет | цвет | 0 … 1 | 0,56 |
| `splash` | Брызги | вкл/выкл | 0 / 1 | 1 |

### Огонь — `fire`

![Огонь](media/fire.gif)

Классический алгоритм «Doom fire» на мелкой сетке 30 × 80: нижний ряд подогревается шумом, тепло поднимается вверх со случайным сдвигом и остывает. Сетка семплируется в координатах клавиш, тепло переводится в цвет по палитре «чёрный → тёмно-красный → оранжевый → жёлтый → белый». Плюс летящие искры и тлеющие угли на нижнем ряду. Симуляция идёт с фиксированной частотой 45 шагов в секунду и не зависит от FPS.

**Нажатие:** клавиша вспыхивает жаром, из неё вылетают 6 искр.

| Параметр | Название | Тип | Диапазон | По умолчанию |
|---|---|---|---|---|
| `height` | Высота пламени | число | 0,3 … 2 | 1,2 |
| `intensity` | Жар | число | 0,3 … 1,5 | 1 |
| `wind` | Ветер | число | −1,5 … 1,5 | 0 |
| `sparks` | Искры | число | 0 … 2 | 1 |
| `cool` | Синее пламя | число | 0 … 1 | 0 |

### Эквалайзер — `music_eq`

![Эквалайзер](media/music_eq.gif)

19 полос спектра системного звука, по одной на столбец клавиатуры (басы слева, высокие справа). Высота столбика — уровень полосы, верхняя клавиша загорается плавно. Белые «пики» падают медленнее столбиков. Работает с любым звуком из колонок или наушников — см. [анализ звука](ARCHITECTURE.md#анализ-звука).

| Параметр | Название | Тип | Диапазон | По умолчанию |
|---|---|---|---|---|
| `sensitivity` | Чувствительность | число | 0,3 … 3 | 1 |
| `style` | Цвет: 0 зелёный→красный, 1 радуга | вкл/выкл | 0 / 1 | 0 |
| `hue` | Сдвиг цвета | цвет | 0 … 1 | 0 |
| `caps` | Падающие пики | вкл/выкл | 0 / 1 | 1 |

### Пульс на басах — `music_pulse`

Клавиатура дышит басом из центра. На каждый удар баса из центра расходится кольцо, а цвет сдвигается на шаг. Высокие частоты рассыпают по клавишам короткие белые искры.

| Параметр | Название | Тип | Диапазон | По умолчанию |
|---|---|---|---|---|
| `sensitivity` | Чувствительность | число | 0,3 … 3 | 1 |
| `hue_step` | Смена цвета на долю | число | 0 … 0,5 | 0,13 |
| `sparkle` | Искры от высоких | число | 0 … 2 | 1 |

### Матрица — `matrix`

![Матрица](media/matrix.gif)

Потоки падают по столбцам с яркой головой и затухающим хвостом. Клавиши в хвосте мерцают — «символы» меняются.

**Нажатие:** новый поток стартует с нажатой клавиши.

| Параметр | Название | Тип | Диапазон | По умолчанию |
|---|---|---|---|---|
| `density` | Плотность | число | 0,2 … 3 | 1 |
| `speed` | Скорость | число | 0,3 … 3 | 1 |
| `hue` | Цвет | цвет | 0 … 1 | 0,33 |

### Северное сияние — `aurora`

![Северное сияние](media/aurora.gif)

Волнистая занавесь света с вертикальной структурой лучей медленно колышется по клавиатуре. Нижний край одного цвета, верхний другого. Вне сияния мерцают редкие звёзды.

**Нажатие:** сияние вспыхивает ярче над нажатой клавишей.

| Параметр | Название | Тип | Диапазон | По умолчанию |
|---|---|---|---|---|
| `speed` | Скорость | число | 0,2 … 3 | 1 |
| `hue1` | Цвет низа | цвет | 0 … 1 | 0,38 |
| `hue2` | Цвет верха | цвет | 0 … 1 | 0,8 |
| `stars` | Звёзды | вкл/выкл | 0 / 1 | 1 |

### Океан / лава — `liquid`

Медленно текущая жидкость (шум с domain warping) в палитре океана (тёмно-синий → бирюзовый → пена) или лавы (чёрный → красный → оранжевый → жёлтый).

**Нажатие:** по поверхности расходится круг.

| Параметр | Название | Тип | Диапазон | По умолчанию |
|---|---|---|---|---|
| `lava` | 0 океан, 1 лава | вкл/выкл | 0 / 1 | 0 |
| `speed` | Скорость | число | 0,2 … 3 | 1 |
| `scale` | Масштаб волн | число | 0,5 … 2 | 1 |

## Классические эффекты

Первые шесть эффектов перенесены из первой версии ([`tools/legacy_ardor.py`](../tools/legacy_ardor.py)) на новый API; к ним добавлены «Дыхание» и «Выключено».

| Эффект | Имя | Описание | Параметры (по умолчанию) |
|---|---|---|---|
| Радужная волна | `wave` | радуга бежит по диагонали | `speed` 0…3 (1), `width` 0,3…3 (1) |
| Плазма | `plasma` | сумма синусоид, переливающиеся цвета | `speed` 0…3 (1) |
| Круги от нажатий | `ripple` | от каждой нажатой клавиши расходится цветное кольцо; в спокойном режиме кольца появляются сами | `speed` 0,3…3 (1), `bg` фон 0…1 (0,3) |
| Вспышки при печати | `typing` | нажатая клавиша вспыхивает и гаснет | `fade` 0,3…3 (1), `hue` (0), `rainbow` вкл/выкл (1) |
| Звёзды | `stars` | клавиши плавно загораются и гаснут в случайном порядке | `density` 0,1…3 (1), `hue` (0,6) |
| Огонь (простой) | `fire_classic` | нижние ряды «горят» случайной яркостью | `height` 0,3…2 (1) |
| Дыхание | `breathe` | один цвет плавно разгорается и гаснет; включается и на экране блокировки | `hue` (0,62), `period` 2…12 с (6) |
| Выключено | `off` | всё чёрное (индикаторы при этом работают) | — |

## Как написать свой эффект

### 1. API

```python
class Effect:
    name = ""        # идентификатор: run.py, settings.json
    title = ""       # название в окне
    params = []      # список Param — из него окно само строит ползунки

    def reset(self): ...                               # создать состояние (вызывается из __init__)
    def render(self, t, dt, presses, calm): ...        # вернуть кадр
```

`render` вызывается 60 раз в секунду и получает:

| Аргумент | Что это |
|---|---|
| `t` | секунды с запуска движка |
| `dt` | длительность прошлого кадра, ≤ 0,1 с |
| `presses` | список индексов клавиш, нажатых с прошлого кадра (пустой в спокойном режиме) |
| `calm` | `True` в спокойном режиме |

и возвращает массив **`(N, 3)`** с цветами RGB в диапазоне **0…1**, по строке на клавишу.

Доступно из `ardor/effects/base.py`:

| Имя | Что это |
|---|---|
| `X`, `Y` | массивы координат клавиш в единицах клавиш: `x` 0…18,4 слева направо, `y` 0…5,2 сверху вниз |
| `N` | число клавиш (97) |
| `hsv(h, s, v)` | векторный перевод HSV → RGB, аргументы транслируются (broadcast) до `(N,)` |
| `rgb("ff8800")` | цвет из hex |
| `Noise(rng)` | сглаженный 2D-шум: `noise(x, y)` и фрактальный `noise.fbm(x, y, octaves)` |
| `self.p` | словарь текущих значений параметров |
| `self.rng` | генератор случайных чисел NumPy |

Для эффектов на сетке (как «Огонь») есть `layout.sample(grid)` — билинейная выборка сетки в координатах клавиш. Номер клавиши по имени — `layout.slot_of("Space")`.

`Param(name, title, lo, hi, default, kind)`, где `kind`:
- `"float"` — ползунок (200 шагов);
- `"int"` — ползунок с целыми шагами;
- `"hue"` — ползунок с радугой;
- `"bool"` — галочка (значение 0 или 1).

Значения приходят числом (`float`), даже для `bool`.

### 2. Пример: «Комета»

Создайте `ardor/effects/comet.py`:

```python
"""Comet: a bright dot flies along a row; a key press launches a comet from that key."""
import numpy as np
from .base import Effect, Param, hsv, X, Y, N


class Comet(Effect):
    name, title = "comet", "Комета"
    params = [
        Param("speed", "Скорость", 2.0, 20.0, 8.0),
        Param("tail", "Длина хвоста", 0.5, 6.0, 2.0),
        Param("hue", "Цвет", 0.0, 1.0, 0.08, "hue"),
    ]

    def reset(self):
        self.comets = []                                   # (x старта, ряд, время старта)

    def render(self, t, dt, presses, calm):
        p = self.p
        for k in presses:                                  # нажатие запускает комету от клавиши
            self.comets.append((X[k], Y[k], t))
        if not self.comets:                                # без нажатий — по случайному ряду
            self.comets.append((-1.0, float(self.rng.integers(0, 6)), t))
        v = np.zeros(N)
        alive = []
        for x0, row, t0 in self.comets:
            head = x0 + (t - t0) * p["speed"]
            if head - p["tail"] > 19:                      # улетела за край
                continue
            alive.append((x0, row, t0))
            behind = head - X                              # расстояние от головы назад
            on_row = np.abs(Y - row) < 0.5
            v = np.maximum(v, on_row * (behind >= -0.5) * np.clip(1 - behind / p["tail"], 0, 1))
        self.comets = alive
        return hsv(np.full(N, p["hue"]), 1 - 0.5 * v, v)
```

### 3. Регистрация

В [`ardor/effects/__init__.py`](../ardor/effects/__init__.py):

```python
from .comet import Comet

ALL = [Storm, Rain, Fire, Equalizer, Pulse, Matrix, Aurora, Liquid, Comet,
       Wave, Plasma, Ripple, Typing, Stars, FireClassic, Breathe, Off]
```

Место в `ALL` = место в списке окна и в порядке переключения хоткеями.

### 4. Проверка

```powershell
python run.py --list                 # эффект появился в списке с параметрами
python run.py comet speed=14 tail=4  # запуск на клавиатуре
python tools/render_previews.py comet  # GIF-превью без клавиатуры → docs/media/comet.gif
```

В окне эффект появится автоматически вместе с ползунками; его настройки будут сохраняться в `settings.json`.

### Советы

- **Думайте векторно.** Один вызов `render` должен уложиться в пару миллисекунд: считайте всю клавиатуру одним выражением NumPy, а не циклом по клавишам. Цикл по «объектам» (молниям, кометам, кольцам) — нормально, если их немного.
- **Привязывайтесь к `dt`, а не к кадрам.** Скорости — в «клавишах в секунду», затухание — через `np.exp(-dt / τ)`. Тогда эффект выглядит одинаково при любом FPS.
- **Не забывайте про фон.** Полностью чёрная клавиатура выглядит как выключенная; лёгкий фон (`0.02…0.05`) делает эффект «живым».
- **Подбирайте масштаб `y`.** В существующих эффектах в формулах расстояний `dy` умножается на 1,1…1,6 — коэффициент подобран на глаз, чтобы круги на живой клавиатуре выглядели круглыми.
- **Ограничивайте результат** `np.clip(out, 0, 1)` — движок это сделает и сам, но промежуточные суммы удобнее держать под контролем.
