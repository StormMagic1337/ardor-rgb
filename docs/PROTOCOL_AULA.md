# USB-протокол AULA F75

[English version](PROTOCOL_AULA.en.md) · [Протокол Guardian](PROTOCOL.md) · [← README](../README.md)

Документ описывает, как ARDOR RGB управляет подсветкой клавиатуры **AULA F75** (75%, проводное подключение). Протокол восстановлен по логу обмена фирменной программы OemDrv.exe с клавиатурой; лог снят подменной `hid.dll` ([`tools/aula_hidlog`](../tools/aula_hidlog)) и разобран [`tools/aula_analyze_log.py`](../tools/aula_analyze_log.py). Реализация — [`ardor/devices/aula_f75.py`](../ardor/devices/aula_f75.py).

> Неофициальная информация. Проект не связан с AULA. Используйте на свой риск — см. [отказ от ответственности](../README.md#отказ-от-ответственности).

## Устройство

| | |
|---|---|
| Контроллер | SinoWealth, USB-имя «BY Tech / Gaming Keyboard» |
| VID:PID | `0x258A:0x010C` (кабель); приёмник 2.4 ГГц — `0x3554:0xFA09`, не поддерживается |
| Интерфейс | 1, коллекция **Col06**, usage page `0xFF00` |
| Отчёт | **Feature, report ID 6, 520 байт** (ID + 519) в обе стороны |
| Светодиодов | 80 из 126 слотов |

Вендорских коллекций три (Col03 — Input ID 3, Col05 — Feature ID 5, Col06 — Feature ID 6), подсветка использует только Col06. В Windows коллекции — отдельные устройства, поэтому открывается путь с `col06`:

```python
path = next(d["path"] for d in hid.enumerate(0x258A, 0x010C)
            if d["usage_page"] == 0xFF00 and b"col06" in d["path"].lower())
```

## Формат пакета

| Байт | Значение |
|---|---|
| 0 | `0x06` — report ID |
| 1 | команда; бит `0x80` — чтение |
| 2 | страница (только у `0x03`) |
| 3 | `0x00` |
| 4 | `0x01` |
| 5 | `0x00` |
| 6–7 | длина данных, little-endian |
| 8… | данные |

Контрольной суммы нет. **Чтение:** `SET_FEATURE` с заголовком команды `0x8X` и нулевыми данными, затем `GET_FEATURE` (ID 6) возвращает тот же заголовок и данные с байта 8.

## Команды

| Команда | Длина | Назначение | В ARDOR RGB |
|---|---|---|---|
| `0x82` | 6 | информация об устройстве (ответ `03 00 00 00 00 cd`) | ❌ |
| `0x84` / `0x04` | 128 | прочитать / записать конфигурацию подсветки | ✅ |
| `0x0A` | 512 | записать таблицу цветов эффектов | ✅ при выходе в «Статичный цвет» / «Дыхание» |
| `0x06` | 384 | записать поклавишные цвета эффекта «Свой» (сохраняются в клавиатуре) | ✅ при выходе в «Снимок эффекта» |
| `0x08` | 378 | **кадр в реальном времени** (только RAM) | ✅ |
| `0x03` | 512 × 3 стр. | записать раскладку клавиш | ❌ |

### Конфигурация (128 байт)

| Байт | Значение |
|---|---|
| 9 | `1` в эффекте «Свой», иначе `0` |
| 10 | **эффект**: `0x00` выкл, `0x01` постоянный, `0x02` дыхание, …, `0x15` «Свой» |
| 24 | время сна (`0x0A` = 300 с, таблица `SleepHW` в `KB.ini` программы) |
| 56 + 2·эффект | **яркость** 0…9 этого эффекта (проверено для эффектов 1 и 2) |
| 57 + 2·эффект | старшая тетрада — **скорость** 0…4, младшая — флаги |
| 126–127 | `5A A5` — сигнатура |

OemDrv всегда делает read-modify-write: `0x84` → правка → `0x04` (и `0x0A`, если менялся цвет).

### Таблица цветов (`0x0A`, 512 байт)

По 21 байту (7 цветов RGB) на эффект, блок эффекта N начинается с `21·N`. У эффектов 1…13 по умолчанию палитра «красный, зелёный, синий, жёлтый, пурпурный, голубой, белый»; первый цвет — выбранный пользователем. Байты 506–507 — `5A A5`.

### Поклавишные цвета (`0x06`, 384 байта)

Три плоскости: `R[0..125]`, `G[126..251]`, `B[252..377]`, затем 6 нулей.

### Кадр (`0x08`, 378 байт)

RGB подряд для каждого слота: `[R0 G0 B0 R1 G1 B1 …]`. Проверено на клавиатуре (`AULA_F75_test.txt`, 2026-10-08):

- кадр **виден только при эффекте `0x00` («выкл»)**; поверх других эффектов клавиатура его игнорирует;
- через пару секунд после последнего кадра клавиатура возвращается к сохранённому эффекту — кадры надо слать непрерывно;
- 25 кадров в секунду держатся без проблем (OemDrv в режиме «Музыка» шлёт ~21), ARDOR RGB шлёт 30.

Поэтому при старте ARDOR RGB запоминает конфигурацию, ставит эффект `0x00` и шлёт кадры; при выходе возвращает конфигурацию или оставляет выбранный эффект.

## Номера светодиодов

`LED = столбец · 6 + ряд` — сетка 15 × 6 по физическим столбцам: Esc 0, ` 1, Tab 2, Caps 3, LShift 4, LCtrl 5, Q 8, A 9, F1 12, Space 35, Fn 53, Del 85, PgUp 86, PgDn 87, End 88, Right 89. Полный список с координатами — `_KEYS` в [`aula_f75.py`](../ardor/devices/aula_f75.py); источник — записи `K…` в `Dev\kb\1\KB.ini` фирменной программы (прямоугольник клавиши на картинке и номер светодиода последним полем). Крутилка (84) светодиода не имеет.
